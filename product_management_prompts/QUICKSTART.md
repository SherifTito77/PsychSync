# ⚡ Product Management Prompts - Quick Start

## 🚀 Start in 3 Steps

### 1️⃣ Install Dependencies
```bash
pip3 install flask flask-cors
```

### 2️⃣ Start the Service
```bash
cd product_management_prompts
./start.sh
```

Or manually:
```bash
python3 product_prompt_service.py
```

### 3️⃣ Open in Browser
```
http://localhost:5001
```
