🧹 PsychSync Cache Cleaner

This tool will completely clear all cached PsychSync data from your browser.

⚠️ Important: After clearing cache, go to http://localhost:5174 (NOT 5173!)

Manual Steps (if automatic doesn't work):

  1. Open Chrome DevTools (F12)
  2. Go to "Application" tab
  3. Click "Clear storage" → "Clear site data"
  4. Go to "Service Workers" → Unregister all
  5. Close DevTools
  6. Go to: http://localhost:5174
