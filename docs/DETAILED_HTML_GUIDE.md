## 🎓 Learning Insights

**CSS Animation Technique**: The shimmer effect on progress bars uses `::after` pseudo-element with `translateX` animation. This creates a moving gradient that makes progress bars feel alive and actively updating.

**JavaScript Event Delegation**: Instead of attaching click listeners to every navigation item, we could use event delegation on the parent container for better performance with 50+ navigation items.

**Intersection Observer API**: Used to trigger animations when cards scroll into view, providing smooth entrance animations without complex scroll event listeners.

**CSS Custom Properties**: While not used here (using direct values), a production version could use CSS variables for colors to enable theme switching and easier customization.
