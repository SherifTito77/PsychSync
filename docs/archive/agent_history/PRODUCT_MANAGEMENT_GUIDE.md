## 🎯 Overview

The Product Management Prompts System provides **50 expertly curated prompts** organized into **5 categories** to accelerate product decisions at PsychSync. Each prompt includes:

- **Clear objective**: Specific outcome to achieve
- **Expected outputs**: Deliverables you'll produce
- **Complexity level**: Time and effort required (low/medium/high)
- **Estimated time**: How long to complete
- **Use cases**: When to apply the prompt
- **Related prompts**: Connected prompts for deeper exploration

`★ Insight ─────────────────────────────────────`
**Prompt Design Philosophy**: Each prompt follows the SMART framework:
- **Specific**: Clear, focused objective
- **Measurable**: Defined outputs and success criteria
- **Achievable**: Scoped to realistic timeframes
- **Relevant**: Aligned with product management best practices
- **Time-bound**: Estimated completion time provided

This transforms vague product questions into actionable, structured exercises.

## 🚀 Getting Started

### Access the System

1. Navigate to **Product Management** in the sidebar (🚀 icon)
2. You'll see all 50 prompts organized by category
3. Use filters to find prompts by:
   - **Category**: Roadmap & Strategy, User Experience, Growth, etc.
   - **Complexity**: Low (1-2 hrs), Medium (2-3 hrs), High (3-4+ hrs)
   - **Type**: Strategic, Tactical, Analytical, Technical, Creative, Experimental

### Execute Your First Prompt

1. Browse prompts and select one that matches your current need
2. Click **"Execute Prompt"** button
3. Review the expected outputs and use cases
4. The system tracks your execution for future reference

### Example: Creating a Roadmap

**Prompt**: "Create a roadmap based on user value vs complexity"

**Steps**:
1. Execute the prompt (rs_001)
2. Expected outputs:
   - Prioritized feature matrix
   - Timeline visualization
   - Resource allocation plan
3. Use the related prompts for deeper work:
   - rs_003: Create enterprise strategy
   - gm_003: Turn pain points into opportunities

## 🚀 Advanced Features

### 1. Workflow Builder

Create custom prompt sequences for common scenarios:

**Access**: Click "Build Workflow" button in the main dashboard

**Use Cases**:
- **Feature Launch**: Combine prompts for end-to-end feature delivery
- **Quarterly Planning**: Sequence prompts for strategic planning cycles
- **Retention Improvement**: Chain prompts for churn reduction initiatives

**How to Use**:
1. Click "Build Workflow"
2. Add workflow name and description
3. Add prompts in sequence order
4. Save or execute the entire workflow
5. Export workflow as JSON for sharing

**Example Workflow: Feature Launch**
```
1. rs_002: Generate feature brief (1-2 hrs)
2. an_002: Define product inputs for engineering (1-2 hrs)
3. ux_001: Define user journey (2-3 hrs)
4. op_004: Write UX acceptance criteria (1-2 hrs)
5. op_010: Design announcement playbook (1-2 hrs)

Total Time: ~6-11 hours
```

### 2. AI Prompt Enhancer

Get AI-powered insights for any prompt:

**Features**:
- **Enhanced prompt description** with context
- **Key considerations** for successful execution
- **Success metrics** to measure impact
- **Risks and mitigations** to avoid pitfalls
- **Timeline suggestions** for implementation
- **Resource requirements** for planning

**How to Use**:
1. Execute any prompt
2. Click "Enhance with AI" button
3. Review AI-generated insights
4. Accept enhancement to save with execution
5. Download enhanced prompt as Markdown

`★ Insight ─────────────────────────────────────`
**AI Enhancement Strategy**: The AI enhancer uses product management best practices to:
1. **Contextualize prompts** with your specific situation
2. **Identify success criteria** based on industry standards
3. **Surface common risks** before they become issues
4. **Suggest realistic timelines** based on complexity
5. **Recommend resources** needed for successful execution

This transforms generic prompts into tailored, actionable plans.
`─────────────────────────────────────────────────`

### 3. Export & Sharing

**Export Options**:
- **Single Prompt Results**: Download as JSON or Markdown

## 📡 API Reference

### Base URL
```
http://localhost:8000/api/v1/product-management
```

### Authentication
All endpoints require JWT authentication:
```typescript
Authorization: Bearer <your_jwt_token>
```

### Endpoints

#### Get All Prompts
```http
GET /prompts
```

**Query Parameters**:
- `category`: Filter by category ID
- `complexity`: Filter by complexity (low, medium, high)
- `type`: Filter by type (strategic, tactical, etc.)

**Response**:
```json
{
  "total": 50,
  "prompts": [...],
  "filters": {
    "category": "roadmap_strategy",
    "complexity": "medium",
    "type": "strategic"
  }
}
```

#### Get Categories
```http
GET /categories
```

**Response**:
```json
[
  {
    "id": "roadmap_strategy",
    "name": "Roadmap & Strategy",
    "description": "Strategic planning...",
    "icon": "roadmap",
    "prompt_count": 10
  }
]
```

#### Execute Prompt
```http
POST /prompts/execute
```

**Request Body**:
```json
{
  "prompt_id": "rs_001",
  "context": {
    "team_size": 5,
    "timeline": "Q1 2024",
    "budget": "$50k"
  },
  "use_ai": true
}
```

**Response**:
```json
{
  "prompt": {...},
  "execution_id": 123,
  "executed_at": "2024-01-25T10:30:00Z",
  "use_ai": true,
  "ai_suggestion": "..."
}
```

#### Get Workflow
```http
GET /workflows/{goal}
```

**Goals**: `feature_launch`, `retention_improvement`, `enterprise_expansion`, `quarterly_planning`

**Response**: Ordered list of prompts for the workflow

#### Get Statistics
```http
GET /statistics
```

**Response**:
```json
{
  "total_executions": 150,
  "most_used_prompts": [...],
  "categories_count": 5,
  "total_prompts": 50
}
```

## 💡 Best Practices

### 1. Choose the Right Prompt

**For Strategic Planning**:
- Start with rs_001 (roadmap based on value vs complexity)
- Use rs_010 (North Star Metric) for alignment
- Apply rs_004 (2-year vision) for long-term thinking

**For Feature Development**:
- Begin with rs_002 (feature brief)
- Use an_002 (product inputs for engineering)
- Apply op_004 (UX acceptance criteria)

**For User Engagement**:
- Start with ux_001 (user journey)
- Use ux_007 (customer lifecycle)
- Apply gm_002 (retention levers)

### 2. Build Effective Workflows

**Good Workflow Characteristics**:
- **Logical flow**: Each step builds on previous outputs
- **Time-bound**: Total time fits in a workday or sprint
- **Actionable**: Outputs can be implemented immediately
- **Measurable**: Success criteria are clear

**Example: Quarterly Planning Workflow**
1. rs_001: Create roadmap (2-3 hrs)
2. an_007: Build OKRs (2-3 hrs)
3. an_001: Create KPI dashboard (2-3 hrs)
4. op_003: Design collaboration workflows (2-3 hrs)

**Total**: ~8-12 hours (1-2 day workshop)

### 3. Use AI Enhancement Effectively

**When to Use AI**:
- Complex prompts (high complexity)
- New domains you're unfamiliar with
- Cross-functional initiatives
- Executive stakeholder communication

**What to Provide as Context**:
- Team size and structure
- Timeline constraints
- Budget limitations
- Strategic priorities
- Risk tolerance

### 4. Track and Iterate

**After Executing a Prompt**:
1. Rate the output quality (1-5 stars)
2. Add feedback notes for next time
3. Share results with stakeholders
4. Schedule follow-up if needed

**Quarterly Review**:
- Review most-used prompts

- Create custom prompt templates
- Update workflows based on learnings

### 5. Collaborate with Teams

**Sharing Workflows**:
- Create workflows for common scenarios
- Mark as public for team access
- Export for documentation
- Iterate based on team feedback

**Cross-Functional Usage**:

## ❓ FAQ

### Q: How do I know which prompt to use?

**A**: Start with your current goal:
- **Planning?** → Roadmap & Strategy prompts
- **Building something?** → Operations & Processes prompts
- **Improving metrics?** → Analytics & Metrics prompts
- **Growing revenue?** → Growth & Monetization prompts
- **Improving UX?** → User Experience prompts

Use the search function to find prompts by keyword (e.g., "churn", "pricing", "onboarding")

### Q: Can I create my own prompts?

**A**: Yes! Two options:
1. **Custom Templates**: Create based on existing prompts (via API)
2. **Workflows**: Combine existing prompts into custom sequences

### Q: What's the difference between complexity levels?

**A**:
- **Low (1-2 hrs)**: Straightforward, minimal research
- **Medium (2-3 hrs)**: Requires some analysis and stakeholder input
- **High (3-4+ hrs)**: Complex, cross-functional, extensive research

### Q: How accurate are the time estimates?

**A**: Estimates assume:
- Single contributor
- No major interruptions
- Average research speed
- Standard stakeholder availability

Adjust based on your team size and context.

### Q: Can I use prompts for non-product work?

**A**: Absolutely! Many prompts apply to:
- **Project Management**: Use workflow prompts
- **Marketing Strategy**: Use growth monetization prompts
- **Operations**: Use operations processes prompts
- **Strategy**: Use roadmap and strategy prompts

### Q: How do I integrate this with my existing tools?

**A**:
- **Export**: Download results as JSON/Markdown
- **API**: Build integrations with REST API
- **Workflows**: Share workflow JSON with team
- **Slack/Teams**: Copy outputs directly

### Q: What if a prompt doesn't fit my situation?

**A**:
1. Use AI enhancement to customize
2. Combine multiple prompts
3. Create custom workflow
4. Provide context to tailor outputs
