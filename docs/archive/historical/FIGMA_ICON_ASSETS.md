## 📋 Using These Icons in Figma

### Method 1: Copy-Paste (Quick)
1. Copy the SVG code above
2. In Figma, press `⌘V` (Mac) or `Ctrl+V` (Windows)
3. Figma automatically converts SVG to vector

### Method 2: Import as SVG File (Better for Assets)
1. Create new text file
2. Paste SVG code
3. Save as `.svg` (e.g., `chevron-down.svg`)
4. Drag file into Figma

### Method 3: Create Component (Recommended)
1. Import icon
2. Select icon layer
3. Press `⌘⌥K` to create component
4. Rename with descriptive name
5. Add to component library

### Method 4: Icon Set (Best Practice)
1. Create frame called "Icon Set"
2. Import all icons
3. Organize in grid layout
4. Create components for each
5. Publish as Team Library

## 🎯 Color Variables Setup

### Apply Variables to Icons

After importing icons:
1. Select icon layer(s)
2. In Design panel → Fill → click color
3. Click "Variables" icon (four-dot square)
4. Select appropriate variable:
   - `colors/sections/clinical` for clinical icons
   - `colors/sections/email` for email icons
   - `colors/sections/analytics` for analytics icons
   - etc.

### Icon Color Reference

