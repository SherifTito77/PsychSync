`★ Insight ─────────────────────────────────────`
**Icon System Architecture**: The master icon (🔗) represents the **orchestrator pattern**—a central hub coordinating multiple data sources. Each satellite node represents a **category** of integration, color-coded for **visual distinction**. This **hub-and-spoke** metaphor is universally understood (network topology, organizational charts, solar systems), making the system **intuitively graspable** without explanation.

**Emoji Fallback**: While SVG icons provide **crisp rendering** and **animation support**, emoji serve as **fallbacks** and **quick references**. This dual approach ensures **graceful degradation**—if SVGs fail to load or during development, emoji maintain **semantic meaning**. The reference tables use emoji for **readability** and **copy-paste simplicity**.

**Categorization Strategy**: Icons are grouped by **functional domain** (communication, productivity, HR) rather than technical implementation. This **user-centric organization** aligns with **mental models**—managers think "I need communication data" not "I need the Slack integration". This reduces **cognitive load** and improves **discoverability**.
