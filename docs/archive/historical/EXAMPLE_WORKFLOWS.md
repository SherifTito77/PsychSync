# Example Workflow Templates for Product Management Prompts

This document provides ready-to-use workflow templates for common product management scenarios.

---

## 🚀 Feature Launch Workflow

**Goal**: Take a feature from concept to successful launch
**Total Time**: 6-11 hours
**Prompts**: 5

### Steps

1. **rs_002**: Generate feature brief for team analytics (1-2 hrs)
   - Define the feature and its objectives
   - Identify target users and use cases
   - Outline key requirements

2. **an_002**: Define product inputs for engineering specs (1-2 hrs)
   - Create detailed functional requirements
   - Define acceptance criteria
   - Specify technical constraints

3. **ux_001**: Define the ideal user journey (2-3 hrs)
   - Map user touchpoints
   - Identify friction points
   - Design optimal flow

4. **op_004**: Write UX acceptance criteria (1-2 hrs)
   - Define testable UX criteria
   - Create QA checklist
   - Specify success metrics

5. **op_010**: Design product-announcement playbook (1-2 hrs)
   - Create communication templates
   - Plan launch sequence
   - Prepare announcement materials

### When to Use
- Launching new features
- Releasing major updates
- Rolling out user-facing changes

### Expected Outcomes
- Complete feature specification
- Engineering-ready requirements
- User journey documentation
- Test acceptance criteria
- Launch communication plan

## 🎯 How to Use These Workflows

### 1. Select a Workflow
Choose the workflow that matches your current scenario.

### 2. Execute in Sequence
Follow the prompts in order, completing each before moving to the next.

### 3. Adapt as Needed
Modify workflows based on your specific context and constraints.

### 4. Save Your Work
Export results and create documentation for stakeholders.

### 5. Iterate and Improve
Review what worked and refine workflows for next time.
