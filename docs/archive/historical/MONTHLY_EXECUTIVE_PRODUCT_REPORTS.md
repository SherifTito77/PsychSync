# Monthly Executive Product Reports
**Definition, Templates, and Operational Cadence**

**Date:** January 12, 2025
**Status:** Active Framework
**Audience:** CEO, CPO, CTO, VP Sales, VP CS, Head of Data Science, Head of ML

---

## 🎯 Purpose

Monthly executive product reports provide leadership with a **20-minute monthly snapshot** of product health, velocity, and strategic progress. These reports enable rapid decision-making without requiring deep dives into operational data.

**Core Principles:**
- **Signal, not noise** - Focus on leading indicators, not lagging metrics
- **Actionable intelligence** - Every metric drives a decision or action
- **Trend-based** - Show 3-month trajectories, not point-in-time snapshots
- **Red/yellow/green** - Immediate visual clarity on health

---

## 📊 Report Structure: 3-Layer Framework

### Layer 1: Executive Dashboard (CEO Focus) - 5 minutes
**5-7 KPIs that indicate overall business health**

### Layer 2: Product Health Report (CPO Focus) - 10 minutes
**Product-specific metrics, velocity, quality, user feedback**

### Layer 3: Deep Dive (Rotating) - 5 minutes
**Monthly deep-dive into one strategic area (ML, Security, UX, Infrastructure)**

## 📊 Data Sources & Query Templates

### SQL Queries (Examples)

#### Executive Dashboard Queries
```sql
-- ARR Growth
SELECT
  DATE_TRUNC('month', created_at) as month,
  SUM(annual_contract_value) as arr
FROM subscriptions
WHERE status = 'active'
GROUP BY month
ORDER BY month DESC
LIMIT 3;

-- Activation Rate
SELECT
  COUNT(DISTINCT CASE WHEN first_assessment_completed_at <= created_at + INTERVAL '5 days'
    THEN team_id END) * 100.0 / COUNT(*) as activation_rate_pct
FROM teams
WHERE created_at >= NOW() - INTERVAL '30 days';

-- 90-Day Retention
SELECT
  COUNT(DISTINCT CASE WHEN last_active_at >= created_at + INTERVAL '90 days'
    THEN team_id END) * 100.0 / COUNT(*) as retention_90day_pct
FROM teams
WHERE created_at <= NOW() - INTERVAL '90 days';
```

#### Feature Performance Queries
```sql
-- Team Personality Map Adoption
SELECT
  COUNT(DISTINCT team_id) * 100.0 / (SELECT COUNT(*) FROM teams WHERE created_at >= NOW() - INTERVAL '90 days')
    as team_map_adoption_pct
FROM team_personality_maps
WHERE created_at >= NOW() - INTERVAL '90 days';

-- Slack Integration Adoption
SELECT
  COUNT(DISTINCT team_id) * 100.0 / (SELECT COUNT(*) FROM teams WHERE created_at >= NOW() - INTERVAL '90 days')
    as slack_adoption_pct
FROM slack_integrations
WHERE connected_at >= NOW() - INTERVAL '90 days';

-- DAU/MAU Ratio
SELECT
  COUNT(DISTINCT user_id) * 100.0 / (SELECT COUNT(DISTINCT user_id) FROM user_activity WHERE activity_date >= NOW() - INTERVAL '30 days')
    as dau_mau_pct
FROM user_activity
WHERE activity_date >= NOW() - INTERVAL '1 day';
```

#### ML Model Performance Queries
```sql
-- Conflict Prediction Accuracy
SELECT
  COUNT(CASE WHEN predicted_conflict = actual_conflict THEN 1 END) * 100.0 / COUNT(*) as accuracy_pct
FROM conflict_predictions
WHERE prediction_date >= NOW() - INTERVAL '30 days'
  AND actual_conflict IS NOT NULL;

-- Model Drift Detection
SELECT
  prediction_date,
  AVG(CASE WHEN predicted_conflict = actual_conflict THEN 1.0 ELSE 0.0 END) as accuracy_over_time
FROM conflict_predictions
WHERE prediction_date >= NOW() - INTERVAL '90 days'
  AND actual_conflict IS NOT NULL
GROUP BY prediction_date
ORDER BY prediction_date DESC;
```

## 📋 Dashboard Tools & Visualization

### Recommended Tools
- **Executive Dashboard:** Tableau or Power BI (auto-refresh)
- **Product Health:** Mixpanel + Amplitude (funnel analytics)
- **Technical Metrics:** Grafana + Prometheus (infrastructure monitoring)
- **ML Performance:** MLflow or Arize (model monitoring)
- **User Feedback:** Delighted or Typeform (NPS surveys)
- **Bug Tracking:** Linear or Jira (integrates with engineering)

### Dashboard Access
- **CEO:** Executive dashboard + product health summary
- **CPO:** Full access to all dashboards
- **CTO:** Technical metrics + infrastructure dashboards
- **VP Sales:** Acquisition + activation metrics
- **VP CS:** Retention + engagement + user feedback
- **Head of Data Science:** ML performance + scientific validity
- **Head of ML:** Model metrics + drift monitoring

## ✅ Success Criteria

### Report Quality Standards
- [ ] All red metrics have assigned owners + 7-day action plans
- [ ] All yellow metrics have documented 30-day improvement plans
- [ ] Executive review meeting occurs monthly (60 minutes, on calendar)
- [ ] Deep dive rotates through all 6 areas every 6 months
- [ ] All data queries are automated (no manual data entry)
- [ ] Dashboards auto-refresh daily
- [ ] Action items are tracked and reviewed monthly

### Report Impact Measures
- [ ] Time from data collection to actionable insights: <10 business days
- [ ] Executive decision velocity: 5 decisions made per monthly review
- [ ] Red metric resolution: 80% resolved within 60 days
- [ ] Yellow metric improvement: 70% improve to green within 90 days
- [ ] Data accuracy: >99% (verified via monthly audits)
