# Route to appropriate scoring algorithm based on framework
framework = assessment.framework_code.upper()

if framework == "MBTI":
    return await self._calculate_mbti_scores(assessment, responses)
if framework == "BIG_FIVE":
    return await self._calculate_big_five_scores(assessment, responses)
if framework == "DISC":
    return await self._calculate_disc_scores(assessment, responses)
if framework == "ENNEAGRAM":
    return await self._calculate_enneagram_scores(assessment, responses)

### 3. MBTI Scoring Algorithm
```python
# MBTI dichotomies: E/I, S/N, T/F, J/P
e_score, i_score = 0, 0
s_score, n_score = 0, 0
t_score, f_score = 0, 0
j_score, p_score = 0, 0

# Score calculation based on question patterns
for response in responses:
    if response.answer_value is not None:
        question_id = response.question_id.lower()
        value = response.answer_value

        # Pattern matching for dichotomies
        if any(qid in question_id for qid in ["e1", "e2", "e3", "e4"]):
            if value >= 4:
                e_score += 1
            else:
                i_score += 1
        # ... similar for other dichotomies

# Determine 4-letter MBTI type
mbti_type = ei_preference + sn_preference + tf_preference + jp_preference
```

## Lessons Learned

### 1. Core Business Logic Can Be Preserved
Even complex psychometric algorithms can be preserved during refactoring:
- Copy algorithm logic exactly
- Maintain all mathematical calculations
- Preserve bug fixes
- Add infrastructure around the algorithms

### 2. Read-Only Services Extend Successfully
Services that don't manage data still benefit from BaseService:
- Structured logging with EventType
- Caching for expensive operations
- Error handling patterns
- Architectural consistency

### 3. Caching Strategy Matters
For expensive calculations:
- 30-minute cache appropriate for completed assessments
- Cache key includes assessment_id and user_id
- Results are deterministic (same inputs = same outputs)
- Significant performance improvement expected

### 4. Algorithm Preservation Critical
When refactoring services with domain logic:
- Maintain exact mathematical formulas
- Preserve edge case handling
- Keep bug fixes
- Verify calculation accuracy after migration

### 5. Framework Routing Pattern
Clean separation of concerns:
- Entry point (`calculate_score`) routes to framework-specific methods
- Each framework has dedicated implementation
- Generic fallback for unknown frameworks
- Easy to add new frameworks

## Psychometric Framework Details

### MBTI (Myers-Briggs Type Indicator)
- **16 Types**: INTJ, INTP, ENTJ, ENTP, INFJ, INFP, ENFJ, ENFP, ISTJ, ISFJ, ESTJ, ESFJ, ISTP, ISFP, ESTP, ESFP
- **4 Dichotomies**: E/I, S/N, T/F, J/P
- **Scoring**: Question pattern matching + confidence calculation
- **Output**: 4-letter type + dichotomy scores + interpretation

### Big Five (Five-Factor Model)
- **5 Traits**: Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism
- **Scoring**: Normalized 0-100 scale, question pattern matching
- **Levels**: Very High, High, Moderate, Low, Very Low
- **Output**: 5 trait scores + levels + interpretation

### DISC (Behavioral Styles)
- **4 Styles**: D (Dominance), I (Influence), S (Steadiness), C (Conscientiousness)
- **Scoring**: Normalized 0-100 scale, pattern matching
- **Patterns**: Primary + secondary style combinations
- **Output**: Style scores + primary/secondary + interpretation

### Enneagram
- **9 Types**: Reformer, Helper, Achiever, Individualist, Investigator, Loyalist, Enthusiast, Challenger, Peacemaker
- **Scoring**: 1-5 scale, type-specific questions
- **Wings**: Adjacent types (e.g., Type 1 has wings 2 and 9)
- **Output**: Primary type + wing scores + interpretation

### Generic
- **Scoring**: Simple percentage of total score
- **Interpretation**: Exceptional, Strong, Good, Average, Below Average, Development Needed
- **Use Case**: Assessments without specific framework
