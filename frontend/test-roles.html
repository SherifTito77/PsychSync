Not logged in

How to use

  1. Open your browser's Developer Console (F12)
  2. Paste one of the commands below to set your role
  3. Refresh the page to see the badge

Set Role Commands (run in browser console)

1. Set as Admin

const user = JSON.parse(localStorage.getItem('user') || '{}');
user.role = 'admin';
user.is_superuser = true;
localStorage.setItem('user', JSON.stringify(user));
location.reload();

2. Set as HR

const user = JSON.parse(localStorage.getItem('user') || '{}');
user.role = 'hr';
user.is_superuser = false;
localStorage.setItem('user', JSON.stringify(user));
location.reload();

3. Set as Manager

const user = JSON.parse(localStorage.getItem('user') || '{}');
user.role = 'manager';
user.is_superuser = false;
localStorage.setItem('user', JSON.stringify(user));
location.reload();

4. Set as Employee

const user = JSON.parse(localStorage.getItem('user') || '{}');
user.role = 'employee';
user.is_superuser = false;
localStorage.setItem('user', JSON.stringify(user));
location.reload();
