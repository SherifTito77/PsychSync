# PsychSync Partnership Program Materials

## Program Overview

PsychSync's Partnership Program is designed to create mutually beneficial relationships with HR consulting firms, HRIS providers, and industry associations. Our program offers competitive commissions, comprehensive support, and collaborative growth opportunities.

## Partnership Tiers

### 1. Referral Partner (Entry Level)
- **Commission**: 20% of first-year contract value
- **Requirements**: No minimum deal flow
- **Support**: Basic sales materials and lead tracking
- **Benefits**: Revenue sharing, co-marketing opportunities
- **Ideal for**: Individual consultants, small consulting firms

### 2. Certified Partner (Professional Level)
- **Commission**: 25% of first-year contract value + 10% renewal revenue
- **Requirements**: 5 deals per year, certification completion
- **Support**: Dedicated partner manager, advanced training, demo environment
- **Benefits**: Higher commissions, lead distribution, joint sales calls
- **Ideal for**: Established HR consulting firms, boutique agencies

### 3. Strategic Partner (Enterprise Level)
- **Commission**: 30% of first-year contract value + 15% renewal revenue
- **Requirements**: 15 deals per year, $1M+ pipeline, exclusive territory
- **Support**: White-glove onboarding, custom integrations, dedicated technical team
- **Benefits**: Maximum commissions, exclusivity rights, revenue sharing on custom solutions
- **Ideal for**: Large consulting firms, HRIS platform providers

#### Commission Tracking System
```typescript
// Partner Commission Calculator
class CommissionCalculator {
  calculateCommission(
    deal: Deal,
    partnerTier: PartnerTier,
    referralType: ReferralType
  ): CommissionResult {
    const baseCommission = this.getBaseCommissionRate(partnerTier, deal.contractValue);
    const multiplier = this.getReferralMultiplier(referralType);
    const bonusThresholds = this.getBonusThresholds(partnerTier);

    let commission = baseCommission * multiplier;

    // Apply volume bonuses
    const volumeBonus = this.calculateVolumeBonus(deal.contractValue, bonusThresholds);
    commission += volumeBonus;

    // Apply accelerator for early close
    if (deal.closeWithin <= 30) {
      commission *= 1.1; // 10% accelerator
    }

    return {
      totalCommission: commission,
      baseCommission: baseCommission * multiplier,
      volumeBonus,
      accelerator: commission - (baseCommission * multiplier + volumeBonus),
      paymentSchedule: this.getPaymentSchedule(partnerTier)
    };
  }

  private getBaseCommissionRate(tier: PartnerTier, dealValue: number): number {
    const rates = {
      referral: { min: 0.20, max: 0.25 },
      certified: { min: 0.25, max: 0.30 },
      strategic: { min: 0.30, max: 0.35 }
    };

    const tierRates = rates[tier];
    const valueMultiplier = dealValue >= 100000 ? 1.1 : 1.0;

    return tierRates.min * valueMultiplier;
  }
}
```
